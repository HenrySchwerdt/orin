- **Multiple type-parameter bounds (ADR-0034, ADR-0040).** A type parameter of a function, class or method can list several bounds joined with `&`, such as `T extends Ord & Hash` or `K extends Shape & Scaled`. A type argument must satisfy every bound, the body sees the members of all of them, and two bounds that declare the same method with different signatures are the new error E0477 (a duplicate bound is E0304). `E0408` is no longer reported for `&`; the formatter prints bound lists (and the bounds of generic methods), and the `std:meta` JSON carries an optional `bounds` key. Derived and explicit `Eq`/`Ord`/`Hash` work with any combination; both backends are unchanged because instances are monomorphised.
