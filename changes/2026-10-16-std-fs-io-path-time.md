- **`std:fs`, `std:io`, `std:path` and `std:time` follow ADR-0048 (typed errors, no sentinels, no traps for ordinary failure).** `std:fs`: `FsError` is no longer `string` but a record `{ kind: FsErrorKind, op: FsOp, path, reason }` with `FsErrorKind = NotFound | PermissionDenied | IsDirectory | NotDirectory | AlreadyExists | Denied | OutsideScope | ReadOnly | WrongMode | TooManyFiles | Io` and `fsErrorMessage(e)` ("cannot read 'p': No such file or directory"); `readFile`, `writeFile` and every `with*File*` / `use*File*` scope return `Result<_, FsError>`; `exists(fs, path)` now returns `Result<bool, FsError>` and `listDir(fs, path)` `Result<string[], FsError>` instead of trapping when the grant refuses the query or the directory cannot be read (a failure found at close now reads "I/O error on 'p': reason"). `std:io`: `shell(proc, cmd)` and `shellTimeout(proc, cmd, timeout: Duration)` return `Result<int, ProcessError>` with `ProcessError = { kind: ProcessErrorKind, command }`, `ProcessErrorKind = Timeout | InvalidDuration | Failed` and `processErrorMessage(e)`; the `-1` / `-2` sentinels and the `seconds: int` parameter are gone (a fraction of a second rounds up; exit status 124 is an ordinary `Ok(124)`). `std:io` is now a library module over the internal builtins `shellRaw` / `shellTimeoutRaw`. `std:path`: `join(base, part)` takes two parts (the array form is `joinAll(parts)`; the old one-argument `join(parts)` has no wrapper because the name is reused), `replaceExtension(p, ext)` replaces `withExtension` (deprecated wrapper kept). `std:time`: `durationBetween(start, end)` and `instantAfter(instant, d)` replace `between` and `plus` (deprecated wrappers kept); the monotonic API is unchanged. `std:fs`, `std:host` and `std:io` are unstable, so the breaking changes there have no wrappers. The signature-first doc comments, `docs/std.md` and the MCP API table are updated, and the compiler and tooling callers use the new API through small helpers (`compiler/util/fs.or`, `compiler/util/process.or`). Runtime: `orin_fs_exists` returns a negative denial code and `orin_fs_list_dir` returns a `Result`. Bootstrap: the seed is refreshed (the compiler now uses the new `std:fs` / `std:io`) and is the `--c-builtins` build of the compiler, so `tools/bootstrap.sh` compiles stage 1 with `--c-builtins` (the C runtime path the frozen `bootstrap/seed/runtime/` snapshot implements; the snapshot got the same two runtime edits). New tests: `tests/std/{fs,io,path,time}_test.or`.
