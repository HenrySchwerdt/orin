- **Concurrency C4: network ownership for concurrent servers (ADR-0017 Addendum C).** An accepted `Stream` can now be moved into a task and a `NetGrant` delegated to one, so a server serves many connections at once. `std:task` gains `spawnNet`, `scopeNet`, `scopeNetDo`; `std:net` gains `acceptDetached`, `Accepted`, `serveAccepted`, `serveAcceptedDo`, `dropAccepted`, `spawnAccepted`, `spawnAcceptedDo`. New error E0487 (library code: a `Listener` moved or a `Stream` cloned); E0483 now also names Listener and Stream captures. The runtime's global net buffer `g_netbuf` is replaced by a per-task buffer; `orin_cap_clone/move` accept net handles and `orin_cap_adopt_net/stream` are new (listed in the porting table of `docs/concurrency.md`; `runtime/platform` unchanged). New `examples/http_server_concurrent.or` (bounded worker pool, request limits, per-connection deadlines) with loopback tests (parallel clients, ThreadSanitizer) in `tools/test_net.sh`, and MIR verifier cases for moved streams.
