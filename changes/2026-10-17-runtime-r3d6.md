- **The C backend defines the object-model inlines itself (ADR-0052 R3d.6).** Generated C starts with a preamble (`compiler/backends/c/preamble.or`) holding the `static inline` helpers it calls, as the LLVM backend always did with `orinl_*`: retain, release and copy-on-write, checked struct and array slot access, array push, checked arithmetic and conversions, the unboxed aggregate types and the `ORIN_CFG_*` constants of `cfg(k)`, named `orinc_*` and with the text the runtime header had, so executed instructions are unchanged on every benchmark (C and LLVM within +-0.00 %, `ORIN_STATS` identical). `runtime/core/orin_runtime_mir.h` is deleted and `orin_runtime.h` keeps only the inlines the C shells of the runtime and their unit tests still call; the `--split N` header and data unit carry the same preamble. No language or CLI change.
