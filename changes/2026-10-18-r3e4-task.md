- **Task interface, step 4: task start, join, message and the trap in Orin (ADR-0052 Addendum B, R3e.4).** `runtime/core/task.or` now holds the task record, `spawn`, the thread entry, `join`, `message`, `watch`, the heap retire at the end of a task and the trap: generated code and the C shells call the Orin `orin_trap` (a wrapper emitted into every program, so the C `orin_trap` is gone from the live runtime), `std:task` calls the Orin start, join, message and watch, and a task thread that traps still ends with `thread_exit` after retiring its heap. A trap prints the same `trap: <message>` line and exits with status 101 on the main thread. There is no user-visible change. A new test `tests/concurrency/trap_deep.or` ends 10,000 tasks on traps at depth, in generated frames and in runtime frames.
