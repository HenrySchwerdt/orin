- **Per-thread heap block (ADR-0052, R3d.1).** The allocator state of a thread (live-object count, struct and array free lists, small-block cache, `orin_destroy` work stack, `orin_stats`) is one exported `__thread` `orin_heap` block of 1024 bytes with documented field offsets, the block `heapBase()` returns. Runtime only; behaviour, counters and task-heap rules are unchanged.
