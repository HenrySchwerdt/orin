- **Lean model: arrays, loops and calls (ADR-0053 M6).** The machine-checked ownership model in `formal/` now covers arrays with length and bounds-checked access (an out-of-range index traps and is never a memory error), structured loops with the invariant found by iterated join, and calls with scalar, borrowed and owned parameters and owned results: `prog_sound` shows that a program accepted by `pcheck` never takes a `bad` step (use after free, double free, store into a shared object) in any callee at any depth, with no `sorry` and only the standard axioms. The call rule is stricter than `compiler/verify` (a call demotes every `Unique` local) and struct shapes are not modelled yet. No compiler, library or runtime change.
