- **Task interface, step 2: transfer between tasks in Orin (ADR-0052 Addendum B, R3e.2).** `runtime/core/transfer.or` implements the value transfer of `std:task` (the slot table with generation tokens, the move-or-copy decision, the iterative uniqueness walk and deep copy, the move/copy counters, the box-once path and the void box) in Orin, so generated code no longer calls the C `orin_rt_transfer_*` functions. The slot table moves into the shared block, with a slot layout both the Orin and the remaining C code (task start, lend) use, so the two share one table. Moves, copies and every `ORIN_STATS` counter are unchanged; there is no user-visible change. A new test `tests/concurrency/transfer_deep.or` moves and copies 200,000-link chains, a million integers and 100,000 strings.
