- **Runtime in Orin, step R3d.0 (ADR-0052).** Orin runtime modules now live in `runtime/core/*.or` (embedded root `$rt`); only
  they can import the core memory operations (`std:core`). New core operations (bit operations, shifts, `memRealloc`,
  `memMove`, `memCmp`, `heapBase`, `cfg`, `expect`), `memAlloc` traps on out of memory, and the bootstrap seed links a frozen
  copy of the pre-R3d C runtime (`bootstrap/seed/runtime/`). All runtime link lines read `tools/runtime-sources.txt`.
  Generated code of ordinary programs is unchanged.
