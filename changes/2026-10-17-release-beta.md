- **Release pipeline for the first beta (roadmap D10).** The release workflow marks a release as pre-release only for `-alpha`, `-beta` and `-rc` versions (title says which) and publishes a plain `x.y.z` as a normal release; a manual run with `dry_run` unticked creates the tag itself, so no tag push is needed. `tools/homebrew_formula.sh --sums` now renders a formula for every platform in `SHA256SUMS` (macOS arm64 and Intel, Linux x86-64 and arm64) with a caveat about the C compiler, and the release gets the rendered `orin.rb` attached.
