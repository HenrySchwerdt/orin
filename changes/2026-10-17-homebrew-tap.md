- **Homebrew tap (ADR-0047 phase 8).** `brew install orin-lang/orin/orin` on macOS (Apple silicon), from the new tap [orin-lang/homebrew-orin](https://github.com/orin-lang/homebrew-orin). `tools/homebrew_formula.sh <version> <sha256 | --sums SHA256SUMS>` renders the formula (pinned release URL and sha256 of the `macos-arm64` package; test: `--version`, `doctor`, `run`, `build`). New job `homebrew` in the release workflow opens a formula update PR on the tap after each published release (secret `HOMEBREW_TAP_TOKEN`; without it the formula is only rendered). Tap README and CI (install, test, uninstall on macos-14) in `dist/homebrew/tap/`. Intel macOS and Linux are not in the formula yet.
