- **`std:json` follows ADR-0048 (section 7.1 module cut, names, errors).** `std:json` is now the exact, bounded model that was `std:jsonvalue` (`JsonValue`, `parseDocument`, `writeDocument`, limits, exact numbers), with submodules `std:json/number` (was `std:jsonnumber`) and `std:json/decode` (was `std:jsondecode`); the integer-only `Json`/`JNum(int)` family moved to `std:json/legacy` (module banner: deprecated) with new bridges `toValue(j): JsonValue` and `fromValue(v): Result<Json, NumberError>`. **Breaking:** `import ... from "std:json"` of the old `Json`, `parse`, `stringify`, `get`, ... must say `"std:json/legacy"`, and the module ids `std:jsonvalue`, `std:jsonnumber`, `std:jsondecode` are gone (no shim; change the import path only). Renames with `@Deprecated` wrappers for one release: `defaultJsonLimits` -> `defaultLimits`, `defaultJsonOptions` -> `defaultReadOptions`, legacy `at` -> `getIndex`, `path` -> `getPath`, `formatError` -> `jsonErrorMessage`. New renderers `jsonParseErrorMessage`, `jsonWriteErrorMessage` and `decodeErrorMessage` (never contain input values). Doc comments are signature-first with errors and cost; `docs/std-json*.md`, the MCP API table, the protocol/explorer/benchmark tooling, `examples/json-codec` and the tests follow, and `tools/embed_prelude.py` now embeds sub-directories of `library/std/`.
