- **`std:url` follows ADR-0048 (migration step 5, error shape).** The boolean `spaceAsPlus` / `plusAsSpace` parameters of `percentEncode`, `percentEncodeBytes`, `percentDecode`, `percentDecodeBytes`, `parseQuery` and `stringifyQuery` (opposite polarity in encoders and decoders) become one required option `space: FormSpace`, with `type FormSpace = PlusAsSpace | PercentSpace`: pass `PlusAsSpace` where you passed `true`, `PercentSpace` where you passed `false`. **Breaking**, no deprecated wrappers (the same names cannot be overloaded). `QueryEncodeError` is now `{ kind: QueryEncodeErrorKind; pairIndex; offset }` with `QueryEncodeErrorKind = InvalidKeyUtf8 | InvalidValueUtf8`; the field `inValue: bool` is gone (`kind == InvalidValueUtf8`). New `queryEncodeErrorMessage(e)`. Doc comments are signature-first with errors and cost; `docs/std-url.md`, the MCP API table and `tests/std/url_test.or` follow.
