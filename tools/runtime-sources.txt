# The runtime source list: the one place that names the C files a compiled Orin program is linked with (ADR-0052 Addendum A
# section 4, step R3d.0). Read by tools/runtime_files.sh, tools/runtime_files.py and tooling/{conformance,differential}.
# Format: `<world>.<kind> = <paths relative to the repository root, space separated>`. Lines starting with # are comments.
#
# world core:   the live runtime (what a program compiled by the current compiler is linked with)
# world legacy: the frozen snapshot bootstrap/seed/runtime/ (stage 0 / stage 1 of tools/bootstrap.sh and the --c-builtins side of
#               tools/differential.sh --mode builtins); its headers find the shared platform layer through the second include dir
# kinds: include (-I directories, in order), sources (always linked), llvm (also linked for the LLVM backend)
core.include = runtime/core
core.sources = runtime/core/orin_runtime.c runtime/platform/orin_platform.c
core.llvm = runtime/core/orin_runtime_llvm.c
legacy.include = bootstrap/seed/runtime runtime/core
legacy.sources = bootstrap/seed/runtime/orin_runtime.c runtime/platform/orin_platform.c
legacy.llvm = bootstrap/seed/runtime/orin_runtime_llvm.c
